# MTP Server для GarlicOS 1.4.9

Сервер открывает файлы оригинальной Anbernic RG35XX по USB через MTP. USB Manager и Toggle MTP управляют одним установленным сервером. Для включения режима достаточно любого из этих приложений.

## Установка на TF1

1. Выключите консоль и подключите системную карту TF1 к компьютеру. Сохраните копии `dmenu.bin` и существующего `usb.sh` из раздела MISC.
2. Из папки `MISC` установочного ZIP скопируйте `usb.sh` в корень раздела MISC, рядом с `dmenu.bin`.
3. В игровой раздел TF1 скопируйте содержимое папки `ROMS` архива. Совместите папку `CFW` с существующей. Получатся `CFW/autostart/mtp.sh`, `CFW/mtp/run.sh` и `CFW/mtp/mtp-server`.
4. Откройте **свой** `MISC/dmenu.bin` как текст. Найдите блок запуска ADB.

```sh
# Enable ADB for debugging
if [ -f /misc/enableADB ]
then
    /usbdbg.sh device
fi
```

Замените только этот блок одной отдельной строкой `/misc/usb.sh`. Сохраните файл с окончаниями строк LF, без BOM. Если отдельная строка уже есть, пропустите правку. Если файл двоичный или ожидаемого блока нет, сохраните исходный файл и проверьте версию прошивки перед продолжением.

5. Безопасно извлеките карту, включите консоль. В **USB Manager** выберите **MTP → Применить** либо запустите **Toggle MTP**. Перезагрузите консоль и подключите USB-кабелем с передачей данных. На ПК откройте устройство RG35XX и проверьте копирование небольшого файла. Перед отключением кабеля дождитесь завершения передачи.

Если с одной картой второе хранилище мешает подключению, в `CFW/mtp/run.sh` задайте `MTP_ENTRY_LEN=1` и перезагрузите приставку. Для отката восстановите резервные копии файлов MISC и удалите только добавленные файлы сервера и флаг `enableMTP`.

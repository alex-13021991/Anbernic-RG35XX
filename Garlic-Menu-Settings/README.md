# Garlic Menu Settings v1.0

Редактор отображения списка игр на оригинальной RG35XX с GarlicOS 1.4.9. Инструкция по переносу на карту и управлению находится в файле «Установка.txt».

## Сборка в Ubuntu 24.04

Приложение написано на C99. Для ARM используются SDL 1.2, SDL_ttf и SDL_image из Miyoo uClibc SDK, GCC 7.3.0. yyjson и SHA-256 входят в исполняемый файл. Сборка и упаковка работают без сети.

Комплект Miyoo распространяется как [env_toolchain.7z](https://github.com/steward-fu/website/releases/download/miyoo/env_toolchain.7z). SHA-256 архива — 70d4ea2d477f931eedbc7e049cddd672098a92c7b9e5672bd90b65143db73c70. Распакуйте в файловую систему Linux с сохранением ссылок. Передайте build.sh путь к каталогу с bin и lib. В использованной WSL он установлен в /home/alex/rg35xx-sdk/miyoo-gcc-7.3.0.

~~~sh
sh build.sh "$HOME/rg35xx-sdk/miyoo-gcc-7.3.0"
python3 package.py ./dist --stock tests/stock
~~~

Результат компиляции — build/garlic-menu-settings, ELF32 ARM EABI5 softfp для Cortex-A9. В исходном ZIP каталог tests/stock содержит контрольные копии предоставленных файлов. В рабочем дереве вместо tests/stock можно передать путь к 001_In/001/Orig. Скрипт упаковки создаёт два ZIP с фиксированными датами и битами исполнения для запуска на Linux.

## Работа с системой

Программа выбирает /mnt/mmc/CFW. Эту точку TF1 использует и системное меню при загрузке шрифтов и языка. Пакет с приложением читается с карты запуска. Хеши stock main, main v0.5 и settings-additions.json зафиксированы в C и в patch/manifest.json. Готовый settings.json из архива патча на карту не копируется.

При установке редактор сохраняет текущие значения всех существующих ключей и добавляет отсутствующие из settings-additions.json. При сохранении редактор изменяет четыре отображаемых параметра. JSON форматируется по одному верхнеуровневому ключу на строку, поскольку v0.5 читает параметры построчно. Вложенные значения и числовая точность сохраняются. Приложение отклоняет неоднозначные повторяющиеся ключи верхнего уровня и файлы больше 4 МиБ. Бэкап содержит исходные байты, включая форматирование.

Приложение берёт исключительную блокировку на каталог CFW. Перед заменой оно готовит и перечитывает копии, публикует журнал в CFW/.garlic-menu.work, использует rename в пределах одного раздела и вызывает fsync для файлов и каталогов. Оно создаёт .bak через O_EXCL. До фиксации операции повторный запуск откатывает изменения, после фиксации завершает проверку и очистку. Перед удалением бэкапов проверяются обе восстановленные копии. CFW/.garlic-menu.original хранит отпечаток исходного JSON конкретной темы, а SHA-256 исходного main известен заранее. Несовпадение с записью или постороннее изменение файла во время восстановления останавливает запись. При ручной установке патча без подтверждённых бэкапов доступны сообщение о состоянии и выход.

## Проверка предпросмотра

Проверялся предоставленный main v0.5 с SHA-256 b20853ebb449a85e7f27562d5d2f945a6bbcb3c3127dfa762ffc8e785e6eb988. Тест выполняет ARM-инструкции размещения строки от 0x14588 и обработчик обрезки от 0x24948 в Unicorn. В точках вызовов SDL_GetTicks и SDL_UpperBlit он подставляет время и считывает исходный и экранный прямоугольники. Затем сравнивает их с результатом функции layout из приложения.

| Выравнивание | Начало строки на экране | Поведение в списке игр |
| --- | --- | --- |
| left | отступ | С обложкой ширина ограничена меньшим из text-max-width и 640 минус отступ. Значение 0 отключает лимит. Прокручивается выбранная длинная строка. |
| center | (640 минус полная ширина строки) / 2 | Меню центрирует полную строку. Обрезка патча и прокрутка выключены. |
| right | 640 минус отступ минус полная ширина строки | Меню выравнивает правый край полной строки. Обрезка патча и прокрутка выключены. |

При отсутствии обложки лимит отключается во всех трёх режимах. Физические края экрана ограничивают видимую часть текста при любом выравнивании. После начальной задержки выделенная строка движется со скоростью из JSON, останавливается в конце на указанное время и возвращается к началу. v0.5 принимает скорость 10–200 px/с и задержки 0–10000 мс. При неподдерживаемых значениях предпросмотр использует значения патча по умолчанию, а исходные параметры времени сохраняются в JSON.

Предпросмотр использует тестовый список из восьми игр и одну демонстрационную обложку. Фон и цвета берутся из текущей темы, шрифт и кегль — из выбранного языка. При отсутствии ресурсов используются встроенный FreeSans и однотонный фон. Обложка в GarlicOS позиционируется содержимым настоящего PNG, поэтому переключатели стороны и видимости действуют только в предпросмотре.

## Воспроизведение тестов

Файловые тесты создают временные каталоги TF1 и TF2. Для эталонного рендера нужен python3-unicorn, для запуска ARM — qemu-arm или qemu-arm-static. Pillow нужен только для повторной генерации рисунков. Тестовые точки отказа и управление тестовой папкой отсутствуют в релизном бинарнике.

~~~sh
sdk="$HOME/rg35xx-sdk/miyoo-gcc-7.3.0"
qemu=$(command -v qemu-arm-static || command -v qemu-arm)
GMS_TEST_BUILD=1 sh build.sh "$sdk"
python3 tests/storage.py tests/stock
python3 tests/check_patch.py
~~~

Для изолированной загрузки старых библиотек создайте каталог runtime. Ссылки учитывают абсолютные RPATH, записанные в библиотеках оригинального SDK.

~~~sh
runtime=$(mktemp -d)
mkdir -p "$runtime/usr" "$runtime/opt"
ln -s "$sdk" "$runtime/opt/miyoo"
ln -s "$sdk/arm-miyoo-linux-uclibcgnueabi/sysroot/lib" "$runtime/lib"
ln -s "$sdk/arm-miyoo-linux-uclibcgnueabi/sysroot/usr/lib" "$runtime/usr/lib"
python3 tests/storage.py tests/stock --qemu "$qemu" --sysroot "$runtime"
python3 tests/ui.py tests/stock "$qemu" "$runtime"
python3 tests/package_smoke.py dist/GarlicMenuSettings-1.0-GarlicOS-1.4.9.zip tests/stock "$sdk" "$qemu" build/test-pad.so
~~~

Проверки охватывают стоковый и пользовательский JSON, повторную установку, ошибочный main, ручной патч, прежние и повреждённые .bak, постороннее редактирование JSON, одновременный запуск, запрет записи, неполные резервные копии, повторное прерывание отката и идентичность восстановленных байтов. Для установки, сохранения и восстановления моделируются соответственно 18, 10 и 17 точек прерывания, а также ошибки операций записи в этих точках. Геометрия и смещения проверяются в 216 сочетаниях. Отдельный набор проверяет 13 сценариев SDL и кнопок. При проверке ZIP эмулятор запускает упакованный релизный ELF со штатным путём TF1 и тестовым источником нажатий. Физическая консоль и настоящая SD в этих проверках не используются.

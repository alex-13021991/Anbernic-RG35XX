# Проверки Preview Editor 1.1.0

Дата подготовки: 27 ноября 2026 года.

## Среда и сборка

Работа выполнена в отдельной копии проекта в WSL Ubuntu 24.04. Для сборки использован доступный Miyoo GCC 7.3.0 с SDL 1.2, SDL_ttf и libpng. Получен ELF32 ARM little-endian, EABI5, загрузчик `/lib/ld-uClibc.so.0`; целевой процессор Cortex-A9, softfp. Компиляция выполняется с `-Wall -Wextra -Werror`.

Исполняемый файл проверялся в QEMU ARM. Сценарий интерфейса извлекает программу из установочного ZIP и запускает её с упакованными ресурсами; подмена SDL-событий подключается только тестовым окружением. Тестовые TF1/TF2 создаются во временной папке Linux.

## Воспроизведение

Из корня Preview-Editor, указав фактический путь к SDK:

```sh
SDK="$HOME/rg35xx-sdk/miyoo-gcc-7.3.0"
PREVIEW_TESTS=1 sh build.sh "$SDK"
python3 package.py dist
python3 tests/run.py dist/PreviewEditor-1.1.0-GarlicOS-1.4.9.zip \
  --sdk "$SDK" --qemu /usr/bin/qemu-arm \
  --frame /tmp/preview-menu.bmp --tools-frame /tmp/preview-tools.bmp
(cd dist && sha256sum -c SHA256SUMS.txt)
```

## Проверка владельцем и ограничения

После получения установочного архива 1.1.0 владелец сообщил: «Получилось отлично!». Это подтверждение пользовательской проверки выданной сборки. Отдельный протокол с моделью SD-карты, журналом запуска и перечнем действий на устройстве не составлялся.

В ходе подготовки публикации исполняемый файл этой сборки не меняется; обновляются документация и упаковка. Автоматические проверки запускаются повторно на окончательном архиве. Новая аппаратная проверка в этой сессии не проводилась. QEMU не воспроизводит физический framebuffer, SD-контроллер и поведение носителя при отключении питания. Тесты проверяют логику приложения и запись на временной Linux-файловой системе.

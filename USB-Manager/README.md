# USB Manager 0.1.2

Настраивает MTP, ADB и USB-ввод. Для оригинальной RG35XX с GarlicOS 1.4.9.

Скопируйте содержимое папки `APPS` из установочного ZIP в `Roms/APPS` на карте TF1 или TF2. Откройте приложение в меню **Консоли → APPS**.

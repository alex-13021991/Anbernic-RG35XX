# Изменения Jazz² RG35XX 1.1.0

## Дополнение — прогон №3

MENU сохраняет штатный resume-прогресс перед выходом. Вибрация восстанавливается после временных ошибок sysfs, активные команды обновляются, GamepadRumble согласован с настройками RG35XX. Добавлены длительный тест и проверка сохранения/продолжения. Подробности и ограничения: [PROGON-03-RU.md](PROGON-03-RU.md).

Версия движка: Jazz² Resurrection 3.7.0. Цель: оригинальная RG35XX (2022), GarlicOS 1.4.9. Релиз 1.1.0 подготовлен 27 ноября 2026 года; финальная сборка — прогон №3.

## Изменения относительно 1.0.0

### Управление

- Основные назначения: A — прыжок, B — огонь, X — бег, Y — смена оружия. Раньше: B, Y, A, X соответственно.
- В меню сохранены A — подтвердить и B — назад. Устранено влияние игровой привязки огня на подтверждение/возврат.
- При назначении занятой кнопки в первом столбце четырёх основных действий назначения меняются местами. Конфликты с дополнительными или защищёнными назначениями отклоняются.
- Названия физических кнопок A/B/X/Y отображаются вместо имён клавиатурных событий.
- При обновлении автоматически меняется только точная старая стандартная раскладка четырёх действий вместе. Пользовательские варианты не сбрасываются.
- Ранние события клавиатуры до создания игрового обработчика больше не вызывают падение.

### Внутреннее разрешение

- Один бинарник с выбором 304×228, 320×240, 384×288, 480×360 и 640×480.
- **По умолчанию 320×240**, вместо 304×228 в 1.0.0/1.1.0-test.
- Параметр сохраняется сразу, применяется после перезапуска игры.
- Вывод framebuffer всегда 640×480. Размер игрового viewport следует выбранному разрешению.
- Размеры меню, загрузки, видеороликов, HUD и уровня следуют активному внутреннему разрешению.

### Ограничение кадров

- Игровой лимит: 30/35/40/45/50/55/60, **по умолчанию 45 FPS**, вместо 30.
- Выбор сохраняется и применяется сразу в игровом процессе.
- Главное меню, пауза, настройки, заставки и загрузка ограничены **30 FPS** независимо от игрового лимита.
- После закрытия паузы восстанавливается выбранный игровой лимит.
- Убрано принудительное `/max-fps:30` из `launch.sh`.

### Штатная вибрация RG35XX

- Управление оригинальным мотором GarlicOS через `/sys/class/power_supply/battery/moto` (сила 0–100).
- В разделе Управление добавлены «Вибрация RG35XX» (Вкл/Выкл) и «Интенсивность вибрации» (Низкая/Средняя/Высокая).
- По умолчанию **Вкл, Средняя**. Масштабы силы: 35%, 65%, 100% от силы эффекта.
- Используются существующие временные шкалы эффектов движка, включая обычные моторы и триггеры, сведённые в один мотор. Это работает с кнопками приставки, которые поступают как клавиатурные события.
- Мотор выключается при завершении эффекта, паузе, входе в меню, отключении опции и выходе. Скрипт запуска дополнительно пишет 0 при завершении.
- Отсутствие/недоступность sysfs-интерфейса не мешает игре; ошибка фиксируется в журнале.
- Для автоматических тестов предусмотрен `JAZZ2_RUMBLE_PATH`, указывающий на файл-модель моторчика. В обычном запуске он не задаётся.

### Совместимость и исходники

- `Jazz2.config` остаётся версии 15; сохранения уровней не удаляются.
- `RG35XX.options` расширен с RGO1 (12 байт) до RGO2 (20 байт): magic, индекс разрешения, игровой FPS, включение вибрации, интенсивность. Все поля — little-endian int32, кроме magic uint32.
- Существующие RGO1 читаются с сохранением выбора разрешения/FPS. Новые поля получают Вкл/Средняя. Валидные сохранённые значения не заменяются новыми defaults.
- Движок восстанавливается из неизменённых vendor-архивов и патчей. Добавлены `RgSettings.h`, `RgRumble.h`, тесты настроек/обмена/FPS/вибрации и отчёты.
- Сборка в WSL Ubuntu 24.04, Miyoo GCC 7.3.0, Cortex-A9/NEON/softfp, uClibc. Исходные скачанные репозитории не изменены.

## Проверки на приставке и QEMU

Владелец подтвердил успешное прохождение аппаратных проверок 1.1.0-test: запуск игры, FPS, переключение разрешений после перезапуска, новая раскладка и обмен назначениями. Финальные изменения дополнительно тестировались в QEMU. После установки прогона №3 владелец подтвердил успешную работу исправленного комплекта на реальной приставке.

Подробности: `VALIDATION-1.1.0.txt` и каталог `validation-1.1.0` в исходном комплекте.

## Подготовленные комплекты

Для GitHub: установочный ZIP без игровых данных, Tools ZIP со свободными ресурсами и конвертерами, полный исходный tar.gz, SHA-256 и подготовленное описание релиза. Отдельный личный ready-to-play ZIP содержит предоставленные владельцем ресурсы и **не включается ни в исходники, ни в каталог публичной публикации**.

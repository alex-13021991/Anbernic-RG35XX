# Jazz² Resurrection для RG35XX — 1.1.0

Jazz Jackrabbit 2 / The Secret Files для **оригинальной Anbernic RG35XX (2022)** с **GarlicOS 1.4.9**. Версия движка — **Jazz² Resurrection 3.7.0**, версия порта — **1.1.0**. Финальная сборка успешно проверена владельцем на реальной приставке — **прогон №3**.

## Что изменено относительно 1.0.0

### Управление и переназначение кнопок

| Действие | Было | Стало |
|---|---|---|
| Прыжок | B | **A** |
| Огонь | Y | **B** |
| Бег | A | **X** |
| Смена оружия | X | **Y** |

- Исправлен обмен занятых основных назначений: выберите первый столбец одного из четырёх действий, нажмите A, затем нужную кнопку. Если она занята первым назначением другого основного действия, назначения поменяются местами.
- Сохранена проверка конфликтов с дополнительными и защищёнными назначениями.
- В списке отображаются физические обозначения A/B/X/Y вместо внутренних имён клавиатурных событий.
- В меню **A — подтвердить, B — назад**, независимо от игровой привязки огня.
- **START / SELECT — пауза / меню**. Крестовина — движение. Дополнительные назначения триггеров сохранены.
- При обновлении автоматически меняется только точная старая стандартная раскладка. Пользовательские варианты не сбрасываются.
- Устранено падение при раннем событии клавиатуры до создания игрового обработчика.

### MENU: сохранить и выйти

Кнопка **MENU** теперь сохраняет игровой прогресс штатным способом движка, записывает настройки, выключает вибромотор и выходит в систему. Раньше сохранялись только настройки.

При следующем запуске выберите **«Продолжить»**. Восстановление идёт **с последней контрольной точки**, как в штатном «Сохранить и выйти» движка. Если открыть файл сохранения не удалось, выход отменяется, а ошибка записывается в журнал. MENU из главного меню просто завершает игру и сохраняет существующий прогресс.

### Выбор внутреннего разрешения

В **Настройки → Графика** добавлен выбор без отдельных бинарников:

| Разрешение | Режим |
|---|---|
| 304×228 | Экономичный |
| **320×240** | **Сбалансированный, по умолчанию** |
| 384×288 | Повышенное качество |
| 480×360 | Высокое качество |
| 640×480 | Нативный |

Параметр сохраняется сразу и применяется **после перезапуска игры**. Выходной framebuffer всегда **640×480**. Размер игрового viewport следует выбранному внутреннему разрешению; размеры меню, HUD, загрузки и видеороликов также учитывают активный режим.

### Настраиваемое ограничение FPS

- Доступны **30, 35, 40, 45, 50, 55, 60 FPS**; по умолчанию **45 FPS**.
- Изменение сохраняется и действует сразу в игровом процессе.
- Главное меню, пауза, настройки, загрузка и заставки ограничены **30 FPS** независимо от игрового лимита.
- После возврата из паузы восстанавливается выбранный игровой лимит.
- Убрано принудительное `/max-fps:30` из скрипта запуска.

Лимит задаёт верхнюю границу; фактическая скорость зависит от сцены и нагрузки на CPU.

### Штатная вибрация GarlicOS

В **Настройки → Управление** добавлены:

- **Вибрация RG35XX** — Вкл / Выкл; по умолчанию **Вкл**.
- **Интенсивность вибрации** — Низкая / Средняя / Высокая; по умолчанию **Средняя**.

Используется встроенный мотор оригинальной RG35XX через штатный интерфейс GarlicOS; внешний геймпад не нужен. Обрабатываются собственные эффекты движка: огонь, урон, смерть, приземление, пружина, разрушение блоков, телепортация и тряска. Их сила масштабируется до **35 / 65 / 100%** от исходного эффекта.

В финальной сборке — прогон №3 — доработана устойчивость вибрации:

- устранена постоянная блокировка после разовой ошибки открытия интерфейса моторчика;
- добавлены повторные попытки после ошибок открытия и записи с интервалом 250 мс;
- активная ненулевая команда периодически обновляется, включая неизменившуюся силу;
- `GamepadRumble` согласован с настройками встроенного мотора, дублирующий пункт внешнего геймпада скрыт;
- мотор выключается при завершении эффекта, в паузе и меню, при отключении опции и выходе; скрипт запуска дополнительно сбрасывает его при завершении процесса;
- в `Logs/log.txt` добавлены счётчики эффектов, записей и ошибок, а также сообщения об отказе и восстановлении.

### Совместимость сохранений и настроек

- Формат `Saves/Jazz2.config` остаётся **v15**.
- Прогресс для продолжения находится в `Saves/Jazz2.resume`.
- Настройки порта хранятся отдельно в `Saves/RG35XX.options`, формат **RGO2**.
- RGO1 из 1.1.0-test читается с сохранением выбранных разрешения и FPS. Новые поля вибрации получают начальные значения Вкл / Средняя.
- Новые значения по умолчанию применяются при отсутствии сохранённых параметров порта. Ваши выбранные разрешение, FPS и назначения не сбрасываются.

## Установка и обновление

1. Сделайте резервную копию папки игры, особенно **Saves**.
2. Распакуйте **Roms** из `Jazz2_RG35XX_v1.1.0.zip` в корень карты с заменой файлов. При обновлении замените **и jazz2, и launch.sh**.
3. Используйте свою уже подготовленную **Content** от 1.0.0 / 1.1.0-test либо создайте её из своей установленной GOG-версии с помощью `Jazz2_RG35XX_Tools_v1.1.0.zip`.
4. Папка Content должна находиться в `Roms/PORTS/Jazz Jackrabbit 2/`.
5. Запустите игру из PORTS. **Saves не удаляйте.**

Системные файлы GarlicOS менять не требуется. Русская локализация, превью, дополнительные библиотеки и конвертер ресурсов сохранены.

## Файлы релиза

- **Jazz2_RG35XX_v1.1.0.zip** — установочный комплект для карты, без игровых данных.
- **Jazz2_RG35XX_Tools_v1.1.0.zip** — Windows/Linux-конвертеры, свободные EngineContent, инструкции и лицензии.
- **Jazz2_RG35XX_v1.1.0-source.tar.gz** — полный исходный комплект: исходники, vendor-архивы, патчи, платформенные адаптеры, сценарии сборки, тесты и русская документация.
- **SHA256SUMS.txt** — SHA-256 всех трёх архивов.

## Проверки

Владелец подтвердил успешную работу финальной сборки **на реальной RG35XX — прогон №3**, после исправлений сохранения по MENU и устойчивости вибрации.

Дополнительно в WSL Ubuntu 24.04 / QEMU проверены ABI и инструкции Cortex-A9, framebuffer 16/32 бита, музыка, управление, настройки, сохранение и продолжение. Вибрация проверялась **65 секунд**, включая искусственное исчезновение интерфейса на две секунды и восстановление без перезапуска. Отдельно моделировались ошибки открытия и записи. Итоговое дерево исходников побайтово воспроизводится из vendor, патчей и платформенных заголовков.

Сборка: **Miyoo GCC 7.3.0, uClibc, Cortex-A9 / NEON / softfp, SDL2 software RGB565**. Подробные инструкции, история изменений и журналы включены в исходный комплект.

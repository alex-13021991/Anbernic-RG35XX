
## Чистая Ubuntu 20.04

Для проверки создано отдельное минимальное окружение Ubuntu 20.04 Focal внутри WSL2. Это chroot Ubuntu 20.04, а не заявление о тестировании команды установки WSL на чистой Windows. Использованы системные GCC 9.4.0, CMake 3.16.3, MinGW-w64 GCC 9.3-posix и отдельно заново распакованный Miyoo GCC 7.3.0.

Старые `build`, `engine`, sysroot и готовая libopenmpt не использовались. Входы: только содержимое `Jazz2_RG35XX` и отдельно установленный SDK. Из включённых архивов распакованы исходники и sysroot, применены все патчи, собраны libopenmpt, ARM-движок, Linux- и Windows-конвертеры. Исходники и целевые библиотеки из других репозиториев не скачивались.

Сравнены 1335 файлов `.h`, `.cpp`, `.c`, `.cmake`, `CMakeLists.txt` исходной аппаратной сборки и чистого восстановленного дерева. После нормализации CRLF/LF различий нет. Это подтверждение соответствия исходников, а не обещание побайтово воспроизводимых ELF: пути/версии хостовых инструментов и метаданные могут менять итоговые хеши.

## Конвертеры

`Tools/AssetPacker.exe` и `AssetPacker-linux` собраны в указанном окружении Ubuntu 20.04 из включённого исходного дерева и zlib. Windows EXE проверен запуском обёртки `Convert.ps1` на Windows; Linux-версия — `scripts/convert.py` в Ubuntu 20.04. Обе полностью обработали установленную GOG Secret Files v1.24, завершились успешно, создали `Prebaked.*` и добавили музыку меню/роликов.

Преобразованные данные проверялись локально и не включались в публикацию. Раскладка `Prebaked.pak` может различаться между хостами из-за порядка обхода файлов; побайтовое совпадение выходных паков не является условием совместимости.

Новая Linux-конвертация проверена с чистой ARM-сборкой в Ubuntu 20.04: 20 секунд уровня, 84 разных снимка, MENU exit=0. Новая Windows-конвертация также проверена запуском уровня с аппаратным бинарником: 20 секунд, 83 разных снимка, MENU exit=0. Дополнительно проверялись бинарник и локальные библиотеки из установочного пакета с фактическими полями RGB GarlicOS.

## Превью и публичные файлы

Превью проверено визуально. Финальный PNG имеет холст 640×480, единственную непрозрачную область (381,56)–(621,416); остальные пиксели прозрачны. Копии в `assets` и `RG35XXPackage/Roms/PORTS/Imgs` совпадают.

Скрипт `release.py` создаёт раздельные архивы игры и утилит, не копирует пользовательские `Content`, `Saves` и `Logs`, отклоняет форматы оригинальной игры и `Prebaked.*`. Для обоих ZIP проверяется целостность, для всех трёх архивов создаётся SHA256SUMS. В исходный архив включены все файлы проекта, обычные деревья `sources` и эталонные архивы `vendor`, без тулчейна. Публикация по просьбе владельца отложена до просмотра.

# Jazz² Resurrection для RG35XX — 1.0.0

Jazz Jackrabbit 2 на **оригинальной Anbernic RG35XX (2022)** с **GarlicOS 1.4.9**. Движок Jazz² Resurrection 3.7.0, программный рендерер, внутреннее разрешение 304×228, экран 640×480, ограничение 30 FPS. Русская локализация сохранена.

На реальной приставке пройден `Rabbit In Training`, загружен `Dungeon Dilemma`, проверены сохранение и продолжение после выхода и повторного запуска. В установившейся игре журнал показывает около 29,6–30 FPS, пик RSS — 30,52 МиБ. Это результат проверенных сцен, а не гарантия скорости во всех эпизодах.

## Скачать и установить

1. Скачайте из [релиза 1.0.0](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/jazz2-rg35xx-v1.0.0) `Jazz2_RG35XX_v1.0.0.zip` — установку игры с превью, и отдельно `Jazz2_RG35XX_Tools_v1.0.0.zip` — конвертеры.
2. Распакуйте `Roms` в корень карты. При обновлении сохраните существующую папку `Saves`.
3. Подготовьте ресурсы своей установленной GOG-версии с помощью приложенного конвертера: [подробная инструкция](docs/CONVERTING.md).
4. Скопируйте полученную папку `Content` в `Roms/PORTS/Jazz Jackrabbit 2/`.
5. Запустите **Jazz Jackrabbit 2** из PORTS.

Системные файлы GarlicOS менять не нужно. Дополнительные библиотеки находятся в папке игры, сохранения — в `Saves`, журналы — в `Logs`. Превью устанавливается в `Roms/PORTS/Imgs/Jazz Jackrabbit 2.png`: холст 640×480, прозрачный фон, обложка 240×360 в позиции (381, 56).

**Игровые данные GOG в публичные пакеты не включены.** Отдельный архив утилит содержит готовые Windows/Linux-конвертеры и собственные свободные ресурсы движка `EngineContent`. Данные самой игры создаются пользователем локально.

## Управление

| Кнопка | В игре |
|---|---|
| Крестовина | Движение |
| B | Прыжок |
| A | Бег |
| Y | Стрельба |
| X | Смена оружия |
| START / SELECT | Пауза / меню |
| MENU | Штатный выход |

В меню A подтверждает выбор, B возвращает назад. Назначения доступны в настройках. Сохраняйте прогресс штатными средствами игры перед выходом.

## Всё необходимое для восстановления проекта

Клонирование или GitHub **Download ZIP** включает все исходные архивы и целевые зависимости. Git submodules, Git LFS, соседние рабочие каталоги и обращения к upstream-репозиториям при сборке не используются.

| Каталог / файл | Содержимое |
|---|---|
| `sources/jazz2-native/` | Полное исходное дерево движка обычными файлами для просмотра |
| `sources/jazz2-miyoo/` | Полное исходное дерево Miyoo-порта обычными файлами |
| `sources/libraries/` | Исходные деревья libopenmpt, OpenAL Soft и zlib |
| `vendor/jazz2-native-b8cba705.tar.gz` | Полное неизменённое дерево исходного движка, commit `b8cba705fb19cb8c747f8367814db47374094f81` |
| `vendor/jazz2-miyoo-3de963ee.tar.gz` | Полное дерево исходного Miyoo-порта, включая его патч, скрипты, документацию и лицензию |
| `patches/miyoo/` | Патч Miyoo, применяемый к движку |
| `patches/rg35xx/`, `platform/` | Наши изменения для RG35XX |
| `vendor/libopenmpt-0.5.34.tar.gz` | Исходники собираемой библиотеки музыки |
| `vendor/openal-soft-1.18.1.tar.gz` | Исходники OpenAL той же версии, что в снимке; в релизе используется готовая библиотека снимка |
| `vendor/zlib-1.2.11.tar.gz` | Исходники zlib для сборки конвертера |
| `vendor/garlicos-1.4.9-build-sysroot.tar.gz` | Заголовки, CRT и нужные готовые библиотеки GarlicOS / SDK; подробное происхождение и хеши сохранены |
| `Tools/` | Конвертер ресурсов, свободные ресурсы движка и обёртки запуска |
| `assets/` | Готовое превью, исходная иллюстрация и описание генерации |
| `scripts/`, `cmake/`, `tests/` | Подготовка, сборка, упаковка и проверки |

Архив **Miyoo GCC 7.3.0** теперь также сохранён в общей папке [Toolchains](../Toolchains/Miyoo-GCC-7.3.0/) с русской инструкцией, SHA-256 и скриптом объединения частей.

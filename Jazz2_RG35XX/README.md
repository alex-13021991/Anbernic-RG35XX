# Jazz² Resurrection для RG35XX — 1.1.0

**Финальная сборка, прогон №3:** MENU теперь вызывает штатное сохранение прогресса перед выходом; исправлены восстановление после ошибок моторчика, обновление активной силы и согласование GamepadRumble. [Подробности](docs/PROGON-03-RU.md).

Jazz Jackrabbit 2 на **оригинальной Anbernic RG35XX (2022)** с **GarlicOS 1.4.9**. Движок Jazz² Resurrection 3.7.0, программный RGB565-рендерер, framebuffer 640×480. Настройки по умолчанию: **320×240**, **45 FPS в игре**, **30 FPS в меню**, встроенная вибрация включена со средней интенсивностью.

## Установка

[Скачать релиз 1.1.0](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/jazz2-rg35xx-v1.1.0).

1. Сохраните резервную копию папки игры, особенно `Saves`.
2. Распакуйте `Roms` из `Jazz2_RG35XX_v1.1.0.zip` в корень карты с заменой файлов.
3. Скопируйте свою подготовленную `Content` в `Roms/PORTS/Jazz Jackrabbit 2/`. Ресурсы от 1.0.0 и 1.1.0-test совместимы.
4. Если ресурсов ещё нет, используйте `Jazz2_RG35XX_Tools_v1.1.0.zip` и [инструкцию конвертации](docs/CONVERTING.md).
5. Запустите игру из PORTS.

Игровые данные GOG и личный ready-to-play архив в публичный релиз и исходники не включены. Системные файлы GarlicOS менять не требуется. При обновлении замените и `jazz2`, и `launch.sh`; папку `Saves` не удаляйте.

## Управление

| Кнопка | В игре |
|---|---|
| Крестовина | Движение |
| A | Прыжок |
| B | Огонь |
| X | Бег |
| Y | Смена оружия |
| START / SELECT | Пауза / меню |
| MENU | Сохранить прогресс и выйти |

В меню A подтверждает выбор, B возвращает назад. В настройках управления первый столбец четырёх основных действий поддерживает автоматический обмен занятых назначений. Дополнительные и защищённые назначения проверяются на конфликт. Старая стандартная раскладка 1.0.0 обновляется автоматически; изменённая пользователем раскладка сохраняется.

## Графика и FPS

Настройки → Графика:

| Внутреннее разрешение | Режим |
|---|---|
| 304×228 | Экономичный |
| **320×240** | **Сбалансированный, по умолчанию** |
| 384×288 | Повышенное качество |
| 480×360 | Высокое качество |
| 640×480 | Нативный |

Разрешение сохраняется сразу и применяется после выхода через MENU и повторного запуска. Framebuffer всегда остаётся 640×480. Размер игрового viewport следует выбранному внутреннему разрешению.

Игровой лимит выбирается из **30, 35, 40, 45, 50, 55, 60 FPS** и действует сразу в игровом процессе. Меню, пауза, настройки, загрузка и заставки ограничены 30 FPS. Изменение игрового лимита в меню не повышает частоту самого меню. Фактическая скорость зависит от нагрузки на CPU.

## Вибрация

Настройки → Управление:

- **Вибрация RG35XX**: Вкл / Выкл, по умолчанию Вкл.
- **Интенсивность вибрации**: Низкая / Средняя / Высокая, по умолчанию Средняя.

Используется штатный мотор через `/sys/class/power_supply/battery/moto`, внешний геймпад не нужен. Эффекты движка (огонь, урон, смерть, приземление, пружина, разрушение блоков, телепортация, тряска) сводятся на один мотор. Интенсивность масштабирует их силу до 35/65/100% от исходной. GamepadRumble движка согласован с переключателем; дублирующий пункт внешнего геймпада скрыт. Мотор останавливается в паузе, меню, при выключении опции и выходе. Скрипт запуска дополнительно сбрасывает мотор при завершении процесса. Если интерфейс отсутствует или недоступен, игра продолжает работать и пишет сообщение в журнал.

## Настройки и совместимость

`Saves/Jazz2.config` сохраняет формат движка версии 15. Параметры порта находятся отдельно в `Saves/RG35XX.options` (RGO2). Существующий RGO1 из 1.1.0-test читается без потери разрешения и FPS; новые поля вибрации получают начальные значения. Новые defaults применяются при отсутствии файла настроек порта. Сохранённые пользовательские значения не заменяются новыми defaults.

Владелец подтвердил работу предыдущей 1.1.0-test на реальной приставке: запуск, немедленное изменение FPS, разрешение после перезапуска, новые назначения и их обмен. Финальная сборка проверена на реальной приставке; точные показатели скорости и длительности работы моторчика на устройстве отдельно не измерялись.

## Исходный комплект

`vendor` содержит неизменённые архивы движка и библиотек, `sources` — исходные upstream-деревья для просмотра. `patches/miyoo` и `patches/rg35xx` применяются сценарием `scripts/source.sh`; `platform` содержит адаптеры RG35XX. Итоговое дерево для компиляции создаётся отдельно в `$JAZZ2_WORK/engine`. Новые изменения идут в `0003-controls-video-options.patch` и `0004-release-defaults-rumble.patch`; исправления прогона №3 — `0005-menu-save-rumble-recovery.patch`.

Локальный SDK GCC 7.3.0 может задаваться через `RG_TOOLCHAIN`. При полном клонировании репозитория SDK также собирается из частей в соседнем `Toolchains/Miyoo-GCC-7.3.0`. Личные ресурсы для компиляции не требуются.

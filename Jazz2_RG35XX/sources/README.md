# Общее дерево исходников

Здесь находятся полные неизменённые исходные деревья обычными файлами:

```text
sources/
├── jazz2-native/                     Jazz² Resurrection 3.7.0
├── jazz2-miyoo/                      исходный порт Miyoo с его патчами
└── libraries/
    ├── libopenmpt-0.5.34/            исходники собираемой ARM-библиотеки музыки
    ├── openal-soft-1.18.1/           исходники версии OpenAL из снимка
    └── zlib-1.2.11/                  исходники zlib для конвертеров
```

Наши изменения находятся рядом, в `../patches/rg35xx` и `../platform`; применяемый Miyoo-патч — в `../patches/miyoo`. Библиотеки, которые не пересобирались, сохранены бинарными файлами в архиве `../vendor/garlicos-1.4.9-build-sysroot.tar.gz` с пофайловым манифестом и [описанием происхождения](../docs/DEPENDENCIES.md).

Эталонные архивы в `vendor` дублируют исходные деревья намеренно: они сохраняют исходную базу патчей и Linux-симлинки независимо от настроек Git/Windows. `scripts/source.sh` распаковывает эталон движка, применяет обе серии патчей и копирует `platform/*.h`. Готовое объединённое дерево появляется в `$JAZZ2_WORK/engine`; оно собирается по [инструкции](../docs/BUILD.md).

При изменении канонических исходников обновляйте соответствующий архив, SHA256SUMS и серию патчей согласованно. Изменение только справочной распакованной копии не изменяет сборку из эталонного архива.

Для просмотра не требуется скачивать что-либо отдельно: эти файлы входят и в общее дерево репозитория, и в полный исходный архив. Вложенные `.git` и оригинальные данные GOG отсутствуют.

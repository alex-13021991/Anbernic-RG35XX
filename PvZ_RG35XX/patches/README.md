Патч применяется с -p1 из каталога pvz в распакованном vendor/pvz-miyoo-2b3c06c-source.tar.gz и даёт точное содержимое sources/pvz. Включает все изменения порта и новые файлы. scripts/verify-patches.py проверяет совпадение SHA256 каждого файла. Инфраструктура сборки/релиза находится в корне и не требует накладывания патчей при обычной сборке.

# История порта
## 1.0.2 — 2026-11-28
Альманах: отключён фоновый прогрев всей коллекции на RG35XX; индекс больше не загружает закрытые растения/зомби. Фоны и карточки страниц лениво загружаются также при входе из главного меню. Неактивная страница освобождается перед загрузкой новой, снижая пик памяти. Бинарник, звук, разрешение и управление сохраняют остальные настройки 1.0.1. См. подробный разбор ALMANAC-1.0.2-RU.md.

## 1.0.1 — 2026-11-28
Тулчейн исключён из исходного комплекта: используется установленный Miyoo GCC 7.3.0 из RG35XX-Development. Добавлено пользовательское превью в PORTS/Imgs. SELECT: x0.5 -> x2 -> x1, с индикатором 0.5X/2X. Удержание MENU уже сохраняло поле; теперь профиль явно сохраняется в ShutdownHook, до освобождения ресурсов. Добавлены проверки цикла скорости и продолжения после выхода.

## 1.0.0 — 2026-11-28
Первый подготовленный стабильный комплект: стандартная ширина 640, корректный fallback 640, полный автономный исходный комплект, SDK/sysroot, применимый патч, инструкции, результаты проверок. Основа игрового кода — проверенная 0.3.0; номер версии в бинарнике обновлён. Подготовлены публичный установщик без данных и личный ready-to-play без сохранений.

## 0.3.0
Настраиваемая ширина 320/400/480/640/800, проекция логических 800×600, исправление кэшированных растений и теней. Тогда default/fallback был 400. Реальное прохождение уровня, проверки геометрии и сценарий QEMU.
## 0.2.3
44100 stereo: темп музыки совпал с Android по сравнению пользователя; стереовывод подтверждён ALSA.
## 0.2.2
Попытка исправить темп сменой частоты mono оказалась недостаточной. Сохранено как история, не рекомендация.
## 0.2.1
Период аудио 1024 → 2048. Заметно меньше провалов на загрузке. Позднее обнаружено ускорение mono.
## 0.2.0
Прямой графический вывод, аудио CPU2. Производительность поля улучшилась; просадки переходов сохранялись.
## 0.1.1
Исправлено чтение крестовины в виртуальном курсоре поля. Пользователь прошёл первый обучающий уровень.
## 0.1.0
Первичный softfp/uClibc-порт, совместимость C++17, framebuffer/evdev по примеру Jazz² Resurrection, MO3-кодеки, исправления завершения и фокуса.

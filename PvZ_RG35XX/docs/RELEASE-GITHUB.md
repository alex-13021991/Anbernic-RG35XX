# Подготовлено для ручной публикации
Подготовлено для alex-13021991/Anbernic-RG35XX, каталог PvZ_RG35XX, tag pvz-rg35xx-v1.0.2. Для публикации используется отдельная рабочая копия; первоначальный локальный клон не меняется.
Каталог PvZ_RG35XX можно целиком добавить в собственный Anbernic-RG35XX/PvZ_RG35XX: все пути вычисляются от каталога проекта. Никаких внешних submodule/LFS.

Tag: pvz-rg35xx-v1.0.2. Заголовок: Plants vs. Zombies Portable RG35XX v1.0.2.

Текст релиза:
> Порт для оригинальной RG35XX / GarlicOS 1.4.9. Полноэкранный вывод 640×480, стандартная внутренняя ширина 640; доступны 320/400/480/640/800 с полным перезапуском. Исправлено управление на поле и ускоренное воспроизведение музыки; добавлены прямой framebuffer-вывод и масштабируемый raster. Полный код, патч к зафиксированному upstream, sysroot и инструкции позволяют собрать игру из одного клона исходников с установленным SDK из RG35XX-Development. Отдельные просадки на переходах и тяжёлых сценах остаются. Подробные тесты — docs/TESTING-RU.md и validation/.

Публично прикладывать: PvZ_RG35XX_v1.0.2.zip (без коммерческих ресурсов), PvZ_RG35XX_v1.0.2_source.tar.gz, контрольные суммы публичных файлов.
Личный PvZ_RG35XX_v1.0.2_ready-to-play.zip НЕ публиковать. Его main_mmp.pak и properties не должны попасть в Git. Сохранений пользователя нет ни в одном подготовленном архиве.

Перед публикацией проверить состав и лицензии системных библиотек (docs/DEPENDENCIES.md). Порт не заявляет права на коммерческие данные Plants vs. Zombies.

SELECT: ×0,5 → ×2 → ×1. Удержание MENU сохраняет профиль и текущий уровень по штатным правилам игры. Превью включено в Roms/PORTS/Imgs/PlantsVsZombies.png.

Версия 1.0.2: целевые проверки альманаха по ADB и QEMU. Историческое подтверждение пользователя относится к 1.0.1.

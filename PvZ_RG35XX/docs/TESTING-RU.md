# Журнал проверок и измерений — 2026-11-28
Данные относятся к оригинальной RG35XX с GarlicOS 1.4.9. Разделяем реальные измерения, наблюдения пользователя и эмуляцию. Ниже исторические результаты; актуальная чистая сборка и тесты дополнены файлами validation/release-1.0.0/.

## Реальная приставка
* Первичный порт загружался со звуком, но крестовина на поле не работала. После исправления 0.1.1 пользователь прошёл обучение.
* При 1008 МГц и полном raster 800×600: главный поток ~94% CPU0, worker ~11%, аудио ~4–5%, screenshot manager ~0,06%; RSS около 151 МиБ; ~17–22 FPS. В окне замера не было активного reclaim/allocstall. Температура около 51°C.
* При 1488 МГц до прямого вывода: ~24–27 FPS, температура ~57–58°C. Частоту менял пользователь. Сцены разные: это не контролируемый A/B.
* 0.2.0 с прямым выводом: примерно 30–33 FPS на 1488 МГц; заикания на переходах/волнах ещё были.
* 0.2.1: пользователь сообщил исчезновение пропусков при загрузке, но позже заметил ускоренный темп. Это не считалось окончательным исправлением.
* Отдельный SDL/ALSA-тест: mono 22050 → ~44372 кадров/с; mono 44100 → ~88744; stereo 44100 → ~44372. Окно около 3 секунд квантовано периодом 2048. Mono фактически проигрывал вдвое быстрее. hw_params номинально этого не показывал.
* 0.2.3 stereo 44100: ALSA подтвердил стереовывод; пользователь сравнил главное меню с Android: «Темп совпадает».
* 0.3.0 raster 400×300/output 640×480 на 1008 МГц: интервалы ~44–87 FPS, часто 50–80; на переходах ~10–20. Пользователь прошёл уровень, отметил меньшую чёткость и отдельные рывки. В логах отдельные underrun остались. Это не строгий A/B одной сцены.
* Пользователь затем проверил 640 и выбрал его: «нравится как идёт игра и графика нормальная». Отдельный численный FPS для 640 не заявляем.
* Настройка 600 в старом launcher не поддерживалась и давала 400: подтверждено конфигом, хешем бинарника и run.log. В 1.0.0 документированы только 320/400/480/640/800 и fallback 640.

## QEMU и проверки исходников до подготовки релиза
* Запуск, меню, Adventure, новый tutorial; посадка двух растений в разные клетки; пауза/возврат; нормальный выход с кодом 0.
* Геометрический тест реальных функций движка: логические/физические размеры, прямоугольники, спрайты, отражение, матрица, повороты 0/90°, треугольники, очистка, кэшированное растение — PASS.
* Декодирование MO3 с mpg123/vorbis: ненулевой sample energy 134953456, предупреждений об отсутствии кодеков 0.
* ABI/сильные импорты сверены с целевым sysroot.

FPS QEMU не используется как показатель скорости приставки. 1.0.0 не объявляется полностью избавленной от просадок. Не подтверждаем прохождение всей игры, всех режимов, длительный стресс-тест или совместимость с другими моделями RG35XX. Исторические сырые замеры сохранены отдельно в validation/history; их сцены и длительности различаются.

## Финальная проверка 1.0.0
* Полная сборка в новом clean-build: вложенный SDK 7.3.0, вложенный sysroot, libopenmpt из вложенного исходного архива, все 201 задачи Ninja завершены; код выхода 0. Внешние SDK/исходные клоны не использовались для этой сборки.
* Распаковка SDK с исключением неиспользуемых системных ссылок: 41555 файлов, Everything is Ok. Контрольные суммы всех частей и общего архива совпали.
* Четыре ARM-тестовых бинарника выполнены под qemu-arm: ввод, viewport/rasterizer, setup conversion, lowres geometry — PASS. Downsample-to-mono в тесте конвертера проверяет отдельную функцию, не настройку воспроизведения игры.
* Проверен launcher: отсутствие файла, все 5 значений, CRLF, 600, мусор и пустое значение; default/fallback 640 — PASS.
* Снимок upstream + наш патч совпадают с полным деревом sources/pvz по SHA256 каждого файла — PASS.
* Установочный код 1.0.0 с ресурсами пользователя запущен через профиль QEMU: лог raster=640x480, output=640x480, audio=44100/channels=2; показано главное меню, выход удержанием MENU, код 0. Профиль запускает ELF напрямую; shell-launcher проверен отдельно. QEMU использует dummy audio и не проверяет физический ALSA.
* Оба ZIP проверены по CRC и внутреннему SHA256-манифесту. Default 640, сохранений/логов/Windows EXE нет. В публичном ZIP нет main_mmp.pak/properties; в личном есть main_mmp.pak и partner_logo.jpg.
* Git-аудит выявил правило core.* в upstream .gitignore, скрывавшее fmt/core.h. Добавлено исключение; обязательные исходники и все части SDK доступны обычному git add.

Полные протоколы и изображение меню: validation/release-1.0.0/. Для 1.0.0 новая установка на приставку ещё не выполнялась; реальные игровые результаты выше относятся к проверенному игровому коду 0.3.0/0.2.3. Финальные изменения затрагивают версию, стандарт launcher и комплектность релиза.

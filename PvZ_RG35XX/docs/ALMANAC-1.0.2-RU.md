# Альманах: разбор задержки и исправление 1.0.2
Дата: 2026-11-28. Оригинальная RG35XX, GarlicOS 1.4.9, raster 640×480. Профиль пользователя: Adventure 2-7.

## Что удалось воспроизвести
Владелец сообщил о зависании при открытии альманаха из главного меню. До действий через ADB сохранена отдельная копия save и журнала. Бинарник на приставке совпал по MD5 с сохранённой установочной 1.0.1: `1db824154954985643ad6db3c9be21e4`.

Первую попытку пользователь прервал кнопкой питания. Последующие SIGKILL и kernel Oops в usb.sh/sysfs относятся к этой последовательности выключения. Их не считаем доказательством падения альманаха или OOM. После повторного запуска исходная 1.0.1 уже не зависла намертво: это отдельно подтверждено пользователем и замером.

Во втором замере 1.0.1 после щелчка:
- В первые ~6 секунд активно подгружались определения анимаций, включая закрытые записи.
- RSS вырос с 135496 до 159724 КиБ; максимальный RSS — 159944 КиБ.
- В переходном окне журнал показал 7,39 FPS, позднее около 28 FPS на индексе.
- Главный поток работал, а не ожидал блокировку. Бесконечный deadlock этим замером не подтверждён.

В первом, ранее длительном игровом сеансе RSS доходил примерно до 178 МиБ, свободной физической памяти оставалось около 5 МиБ, без swap. Это делает дополнительные ресурсы альманаха нежелательными; причина всех возможных зависаний этим одним измерением не установлена.

## Проверка GitHub-источников
Используемая база Miyoo по-прежнему имеет HEAD `2b3c06c203cedf18193f53386b9111364a359e55`. На момент проверки её AlmanacDialog.cpp совпал с нашей исходной 1.0.1. Готового нового исправления поверх этой базы не найдено. Поиск Issues Miyoo по Almanac не дал отдельного сообщения об этом зависании.

В истории уже были изменения:
- [Almanac stutters](https://github.com/Fnava1/pvz-portable-miyoo-/commit/940fabaa5daea917e643ef071447cc1b2bcdf5ae).
- [Almanac pre-warming](https://github.com/Fnava1/pvz-portable-miyoo-/commit/932fd7cc45343a446756700b012c20441ddcd0cd).

Они уже входили в нашу базу. В более ранней [многоплатформенной основе](https://github.com/wszqkzqk/PvZ-Portable) проверен текущий код через GitHub API; механизм прогрева Miyoo является отдельной адаптацией.

## Найденная лишняя работа
`AlmanacDialog::Update()` готовил кэш растений и зомби по очереди, в том числе на стартовой странице и независимо от открытых записей профиля. Подготовка миниатюры могла загрузить полное определение анимации и изображения в главном потоке.

Также отложенная загрузка больших фонов уже существовала, но применялась только при наличии Board. При входе из главного меню Board отсутствует. В результате загружались изображения сразу нескольких страниц. Освобождение старой страницы происходило после загрузки новой либо не происходило в этом пути.

## Изменения 1.0.2
Только для PVZ_RG35XX:
1. Отключён фоновый прогрев всей коллекции альманаха. Видимые миниатюры создаются существующим кодом по необходимости; закрытые записи из-за самого открытия индекса не загружаются.
2. Фоны и карточки страниц загружаются по запросу также из главного меню. Общие кнопки и элементы остаются в общей группе ресурсов.
3. Неактивные фоны/карточки удаляются до загрузки следующей страницы. Предварительно очищаются объекты текущей записи штатным SetPage.
4. В журнале отмечается номер страницы и использование on-demand ресурсов.

Музыка, разрешение, скорость SELECT и формат сохранений не изменялись.

## Проверки
- QEMU: индекс, растения, зомби; изображения и описания; выбор страниц, возврат и штатный выход — PASS.
- Реальная приставка, первый вход после нового запуска: RSS 130168 КиБ в течение ~13 секунд, без роста на ~24 МиБ. Максимальный RSS 131580 КиБ против 159944 КиБ в предыдущем запуске 1.0.1. Это разные запуски с одинаковым профилем, а не побитово одинаковое состояние памяти.
- На приставке открыты обе страницы, выбраны Scaredy-shroom и Newspaper Zombie; изображения, анимации и описания проверены по framebuffer-снимкам. Выполнен повторный вход в альманах.
- Четыре подтверждённых циклических переключения Plants → Index → Zombies → Index. Последовательность страниц подтверждена журналом. Максимальный RSS после навигации 135188 КиБ; продолжительного нарастания памяти в этих циклах не обнаружено.
- Навигация выполнялась через evdev. Для повторяемых серий координаты только виртуального курсора задавались диагностическим средством через /proc/PID/mem; выбор записей и обработка кнопок проходили штатно. Данные профиля этим средством не менялись.
- Полная сборка из исправленного дерева: 199 задач Ninja, Release, GCC 7.3.0 softfp — PASS. Sysroot/libopenmpt взяты из ранее проверенной локальной среды.
- ABI и все сильные импорты — PASS. Тесты ввода, viewport/rasterizer, setup conversion, геометрии lowres, launcher, цикла SELECT и воспроизведения полного дерева патчем — PASS.

Предел проверки: профиль 2-7, а не весь разблокированный альманах и не полное прохождение игры. Краткая загрузка первой выбранной записи ещё возможна. Исправление устраняет обнаруженную лишнюю загрузку; не заявляется устранение любых зависаний при любых условиях.

## Итоговая полная сборка 1.0.2 на приставке
После проверки тестового бинарника установлен отдельно полностью пересобранный Release 1.0.2. MD5 установленного PvZ: `972f7e4d96616170767eb3ec56feb999`, проверен после установки.

- Загружен уровень 2-7 до экрана выбора растений. Альманах открыт щелчком по зомби в предпросмотре; возврат восстанавливает экран выбора.
- Выполнен штатный возврат в главное меню и вход в альманах после загрузки ресурсов уровня.
- RSS перед открытием 152672 КиБ, на индексе 155516 КиБ: прирост около 2,8 МиБ.
- Три новых цикла Plants → Index → Zombies → Index: RSS 156932–156972 КиБ; ещё один выход и повторный вход — 156308 КиБ. Существенного накопления памяти в этом коротком тесте нет.
- Длительность загрузки альманаха при открытии с экрана выбора: в журнале 152 мс. Это таймер конструктора, он не включает последующую отрисовку и не сопоставим напрямую с длительностью старого фонового прогрева.
- Игра оставлена работающей в главном меню, текущий уровень по-прежнему 2-7. Тест не завершал уровень и не подменял профиль.
- Во время перехода с меню в уровень отмечен ALSA underrun. Исправление альманаха не объявляется исправлением всех звуковых пропусков.

## Сохранения и откат
Оригинальная копия save хранится в рабочем каталоге WSL отдельно от релиза. В установочные и исходные архивы она не включена. На TF2 прежний бинарник сохранён как `PlantsVsZombies/PvZ.before-almanac-1.0.1`. При необходимости отката выйти из игры и вернуть его под именем PvZ. Штатное сохранение при MENU проверяется отдельно; оригинальные сохранения не подменялись.

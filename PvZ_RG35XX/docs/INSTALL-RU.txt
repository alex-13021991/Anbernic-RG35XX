Plants vs. Zombies Portable RG35XX 1.0.1
Оригинальная RG35XX, GarlicOS 1.4.9. Архив распаковать в корень TF2.
Roms/PORTS/PlantsVsZombies.sh должен соседствовать с папкой PlantsVsZombies.
Запуск из PORTS. Существующие сохранения перед обновлением скопировать отдельно.
Архив не содержит чужих сохранений; сохранения пользователя лежат в папке save.

render-width.txt: одно число, затем перевод строки.
320 -> 320x240; 400 -> 400x300; 480 -> 480x360;
640 -> 640x480 (ПО УМОЛЧАНИЮ); 800 -> 800x600 (прежний полный путь).
Во всех случаях вывод занимает экран 640x480. Меньшее значение уменьшает
нагрузку и чёткость. После изменения нужен полный выход и новый запуск.
600 не поддерживается. Отсутствующее/ошибочное значение: 640; выбор пишется
в начало run.log. Не ориентируйтесь на старую сборку 0.3.0 с fallback 400.

Управление:
Крестовина — курсор меню / выбор клетки на поле.
A — действие, посадка / щелчок; B — отмена.
В диалоге Continue Game клавиша START подтверждает продолжение.
X — лопата; Y — автоматический сбор солнца.
L/R — переключение пакетов семян; START — пауза; SELECT — цикл скорости: x0.5 (первое нажатие), x2 (второе), x1 (третье).
При старте уровня скорость x1; музыка не замедляется/ускоряется.
MENU — пауза/назад; удержание примерно 1,5 с — сохранение и выход.
Используются штатные правила: профиль сохраняется, текущий уровень — там,
где это допускает игра (как выход через её меню). Питание резко не отключать.
Кнопки громкости — системная громкость.

Звук: 44100 Гц, стерео, период 2048. Для этой ALSA-среды моно приводило
к ускоренному воспроизведению. Первый запуск и загрузка могут быть долгими.
Отдельные рывки на переходах и при большой нагрузке ещё возможны.

Публичному установщику нужны свои ресурсы PC GOTY main.pak; используйте
scripts/prepare-assets.py из исходного комплекта с --properties /путь/к/PC/properties.
Нужны оба компонента своей копии: main.pak и внешняя папка properties. Личный ready-to-play уже
подготовлен. Windows EXE/патчи/crack для запуска не используются.
При проблемах сохраните run.log; перед новым запуском он перезаписывается.

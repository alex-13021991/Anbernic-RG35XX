Dingux Commander Dark RU · 21.11.2026

Выпуск собран штатным Makefile в WSL 2 с Ubuntu 24.04.5 LTS. Использован Miyoo GCC 7.3.0 с uClibc. Владелец подтвердил работу этого бинарника на оригинальной RG35XX под GarlicOS 1.4.9.

Для сборки распакуйте оригинальный Miyoo SDK в файловую систему Linux с сохранением символических ссылок. Архив SDK:
https://github.com/steward-fu/website/releases/download/miyoo/env_toolchain.7z
SHA-256 env_toolchain.7z: 70d4ea2d477f931eedbc7e049cddd672098a92c7b9e5672bd90b65143db73c70

Из каталога Dingux-Commander-RU укажите путь к распакованному каталогу miyoo и выполните:

    sdk=/opt/miyoo
    export LD_LIBRARY_PATH="$sdk/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
    cxx="$sdk/bin/arm-miyoo-linux-uclibcgnueabi-g++"
    sys=$("$cxx" -print-sysroot)
    make -C src -j4 CXX="$cxx" "SDL_CONFIG=$sys/usr/bin/sdl-config --prefix=$sys/usr"

Исполняемый файл: src/output/DinguxCommander
SHA-256 выпущенного ARM-бинарника: 0d49e0403708aad7a2ec9e2843a03dc09403e747e8ba113832b71f7c4d6a525f

Сведения о загрузчике, зависимостях и проверке приведены в verification.txt. Скрипт build.py относится к прежней сборке с Zig для Windows.

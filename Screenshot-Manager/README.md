# Screenshot Manager 0.1.0

Управление службой скриншотов на оригинальной Anbernic RG35XX с GarlicOS 1.4.9. Меню на русском языке показывает, запущена ли служба. Пока она работает, сочетание **L2 + R2** сохраняет снимок в формате PNG в папку `Screenshots` в корне TF1.

### Установка

Скопируйте папку `Roms` из установочного ZIP в корень карты TF1 или TF2, объединив её с существующей папкой. Откройте **Консоли → APPS → Screenshot Manager**.

Если переходите со старого Screenshot Daemon, сначала выключите службу в его меню. Порядок обновления и список старых файлов приведены в [инструкции по установке](Установка.txt).

### Управление

| Кнопка | Действие |
| --- | --- |
| A | Включить или выключить службу. |
| B или MENU | Закрыть меню. Включённая служба продолжает работать. |
| L2 + R2 | Сделать снимок при включённой службе. |

После перезагрузки приставки службу нужно включить снова.

### Исходники

В `src/` находятся исходники меню на C и скрипт запуска. В `Original_Daemon/` сохранён исходный комплект Screenshot Daemon с авторской инструкцией. Для `screenshot`, `printstr` и адаптера ввода `j2k.so` в комплекте есть только готовые ARM-файлы. Сведения о лицензиях меню, шрифта и адаптера находятся в `licenses/`.

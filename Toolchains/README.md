# Тулчейны для оригинальной Anbernic RG35XX

Здесь хранятся архивные копии используемых цепочек компиляции и инструкции на русском языке. Архивы включены обычными Git-файлами: они доступны после `git clone` и GitHub **Download ZIP**, без Git LFS и без обращения к другим репозиториям.

| Тулчейн | Назначение | Сжатый архив |
|---|---|---|
| [Miyoo GCC 7.3.0 / Buildroot 2018.02.9](Miyoo-GCC-7.3.0/) | ARM uClibc, оригинальная RG35XX с GarlicOS; используется для Jazz² Resurrection | 128 828 510 байт, около 123 МиБ |

Оригинальный `env_toolchain.7z` сохранён без изменения содержимого и разделён на три последовательные части по 48 МиБ / 48 МиБ / 26,86 МиБ. Причина — [ограничение GitHub в 100 МиБ на обычный файл](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github). После объединения получается побайтово тот же архив с исходной SHA-256.

Библиотеки и sysroot конкретных приложений хранятся в соответствующих проектах. Для Jazz2 нужен именно sysroot GarlicOS из `Jazz2_RG35XX/vendor`, а не одноимённая файловая система, входящая в общий SDK.

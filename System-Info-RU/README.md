# System Info RU 1.1.1

Системная информация и статистика коллекции для оригинальной Anbernic RG35XX с GarlicOS 1.4.9.

В версии 1.1.1 исполняемый файл пересобран в WSL 2 с Miyoo GCC 7.3.0. По сравнению с 1.1.0 его размер уменьшился с 35 724 до 34 408 байт (на 3,7%).

Работа приложения проверена на оригинальной Anbernic RG35XX с GarlicOS 1.4.9.

- **Система** показывает частоту и загрузку процессора, оперативную память, температуру, заряд и свободное место на картах.
- **Хранилище** считает игры по платформам, приложения, сохранения игр, состояния эмулятора, скриншоты и файлы BIOS. Кнопка **X** переключает сводку и список платформ. Полная проверка по **A** также рассчитывает размер файлов.

## Возможности версии 1.1.0

- В «Хранилище» появился режим «Обе карты». Он складывает показатели TF1 и TF2 и объединяет одноимённые платформы в одну строку. Копия игры на каждой карте учитывается дважды.
- В списке платформ кнопка **Y** переключает сортировку по названию ↑, количеству игр ↓ и размеру ↓. Стрелка в заголовке показывает текущий порядок. Кнопки ↑ и ↓ прокручивают список.
- Запись отладочных журналов отключена. Версия 1.1.0 читает кэш статистики, сохранённый версией 1.0.0.

## Установка

[Скачать System Info RU 1.1.1 для GarlicOS 1.4.9](https://github.com/alex-13021991/Anbernic-RG35XX/releases/download/system-info-ru-v1.1.1/SystemInfoRU-1.1.1-RG35XX-GarlicOS-1.4.9.zip)

Выключите приставку. Скопируйте папку `Roms` из установочного ZIP в корень игрового раздела TF1 или TF2, объединив папки. Достаточно установить приложение на одну карту. Верните карту в приставку и откройте **Консоли → APPS → System Info RU**.

Для обновления с 1.0.0 или 1.1.0 скопируйте файлы на ту же карту и подтвердите замену файлов приложения.

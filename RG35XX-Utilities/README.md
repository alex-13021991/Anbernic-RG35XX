# Общие файлы USB Manager и Screenshot Viewer

Обе программы разрабатывались и собирались вместе. В этой папке находятся общий интерфейс, ресурсы, тесты и архивные сценарии сборки. У каждого приложения собственная папка в корне репозитория.

Чтобы восстановить исходное расположение файлов, из корня репозитория выполните в Python 3 команду `python RG35XX-Utilities/collect.py build-tree`. Команда создаёт новый каталог. Перейдите в него и следуйте [инструкции по сборке](BUILD.md), указав путь к Miyoo SDK. В каждом релизе также приложен оригинальный архив исходников с тем же расположением файлов.

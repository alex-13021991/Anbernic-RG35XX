USB Manager и Screenshot Viewer — 0.1.3
Оригинальная Anbernic RG35XX (2022/2023), GarlicOS 1.4.9
20 ноября 2026

Это ДВА самостоятельных приложения. Можно установить только одно.
Версия 0.1.3 включает обновлённые превью и ровную верхнюю панель в обеих программах.
Не предназначена для RG35XX Plus/H/SP/2024 и GarlicOS 2.x.

УСТАНОВКА
1. Выключите консоль и подключите SD-карту с вашим каталогом Roms/APPS.
2. Из нужного архива скопируйте СОДЕРЖИМОЕ папки APPS в Roms/APPS карты.
   Не создавайте Roms/APPS/APPS. Обе программы можно разместить на TF1 или TF2.
3. Получится, например:
   Roms/APPS/USB Manager.sh
   Roms/APPS/USBManager/usb-manager
   Roms/APPS/USBManager/apply-usb.sh
   Roms/APPS/USBManager/j2k.so
   Roms/APPS/USBManager/res/FreeSans.ttf
   Roms/APPS/Imgs/USB Manager.png

   Roms/APPS/Screenshot Viewer.sh
   Roms/APPS/ScreenshotViewer/screenshot-viewer
   Roms/APPS/ScreenshotViewer/screenshots.cfg
   Roms/APPS/ScreenshotViewer/j2k.so
   Roms/APPS/ScreenshotViewer/res/FreeSans.ttf
   Roms/APPS/Imgs/Screenshot Viewer.png
4. Безопасно извлеките карту, включите консоль. Запускайте из APPS:
   USB Manager или Screenshot Viewer. Интерфейс обеих программ русский.
5. Для обновления сохраняйте свой screenshots.cfg и старые app.log.

USB MANAGER
MTP/ADB/USB-ввод выбираются галочками. Включение USB-ввода снимает MTP и ADB;
включение MTP или ADB снимает USB-ввод. MTP и ADB совместимы.
Все три выключены — дополнительные USB-режимы не запрашиваются на загрузке;
это не отключение физического разъёма или зарядки.

Применить: сохраняет enableMTP, enableADB, waitForUSB в /misc.
НЕ меняет работающие USB-службы, НЕ перезагружает и НЕ прерывает MTP.
После изменения настроек нужен перезапуск консоли, который можно сделать позже.
В приложении нет кнопки перезапуска. Завершите копирование с ПК и перезапустите
консоль штатным способом GarlicOS.
Выход: при несохранённых изменениях спрашивает о выходе без сохранения.
Управление: вверх/вниз — пункт; A — галочка/действие; B или MENU — выход.

Для MTP ДОЛЖЕН быть установлен ваш Toggle_ADB_USB_MTP_RU_GarlicOS_1.4.9.zip,
включая MISC/usb.sh, CFW/mtp и строку /misc/usb.sh в dmenu.bin.
Этот менеджер не устанавливает сервер и не правит dmenu.bin.
Перед первым изменением сохраните резервную копию раздела MISC.
Существующие Toggle-приложения остаются совместимыми, но не запускайте их
одновременно с сохранением настроек в менеджере.

ТЕКУЩИЙ СТАТУС
Индикаторы MTP, ADB и USB-ввода показаны в одной строке. Они читаются из
sysfs и /proc, а не из выбранных галочек.
MTP/ADB учитывают включённые USB-функции и процессы mtp-server/adbd.
«Вкл.» означает настроенную функцию с работающей службой, а не гарантию
успешной передачи данных.
«Нет службы» — функция включена в ядре, но сервер не обнаружен.
USB-ввод определяется по USB role, если ядро её предоставляет; при активном
USB device-режиме показывается «выкл.». Если фактический режим нельзя надёжно
определить, отображается «неизвестно».

Сохранение проверяет ошибки записи и возвращает MISC в режим только чтения.
Для отката незавершённой записи служит /misc/.usb-manager-backup.
При обнаружении такого журнала следующее Применить восстанавливает прежние
флаги и просит заново выбрать настройки. После сбоя восстановления НЕ
перезагружайтесь до проверки MISC; сохраните журнал app.log.

SCREENSHOT VIEWER
Общий список PNG с обеих карт; выбора карты нет. TF1/TF2 — отметка источника.
Одинаковые имена на разных картах — разные файлы. Сортировка: новые сначала,
затем по имени/пути. Если одна карта отсутствует, используется оставшаяся.

Автоматические папки на каждой карте:
  /mnt/mmc/Screenshots                 /mnt/SDCARD/Screenshots
  /mnt/mmc/screenshots                 /mnt/SDCARD/screenshots
  /mnt/mmc/CFW/retroarch/.retroarch/screenshots
  /mnt/SDCARD/CFW/retroarch/.retroarch/screenshots
Также читается screenshot_directory из CFW/retroarch/.retroarch/retroarch.cfg
и CFW/retroarch/retroarch.cfg на каждой карте, если там задан абсолютный путь.
Если RetroArch сохраняет скриншоты рядом с ROM или использует особые пути,
добавьте соответствующие папки в ScreenshotViewer/screenshots.cfg. Весь
каталог ROM автоматически не сканируется. Обложки Imgs не добавляются сами.

Галерея: крестовина — выбор; A — открыть; X — удалить; Y — обновить список;
L1/L2 и R1/R2 — страницы; B или MENU — выход.
Просмотр: влево/вправо или L/R — предыдущий/следующий; Y — размер 1:1;
в режиме 1:1 крестовина двигает изображение, а L/R листают файлы.
B или MENU — возврат в галерею; X — удаление.
Изображение вписывается с сохранением пропорций, без растягивания.

УДАЛЕНИЕ ВСЕГДА С ПОДТВЕРЖДЕНИЕМ: имя + карта, по умолчанию «Отмена».
В диалоге влево/вправо выбирают кнопку, A подтверждает, B отменяет.
Удаление без корзины. Сначала проверьте на ненужном тестовом PNG.
Файл, изменённый после сканирования, не удаляется — обновите список Y.
Не изменяйте одновременно этот же файл через MTP/ADB.

Ограничения первой версии: PNG, до 5000 файлов, глубина подпапок до 12,
до 2048 каталогов. Отдельный PNG: до 4096 по стороне, до 4 194 304 пикселей,
до 32 МБ на диске. Повреждённый/слишком большой файл показывает «Нет превью».
Миниатюры хранятся только для одной страницы; оригинал загружается отдельно.
Изображения не пересохраняются и не превращаются в обложки.

ПЕРВАЯ ПРОВЕРКА НА ПРИСТАВКЕ
1. Проверить запуск, русский текст, крестовину, A/B и выход обеих программ.
2. В USB Manager проверить текущий статус БЕЗ изменения галочек.
3. Проверить выбор MTP+ADB и взаимное исключение USB-ввода.
4. Применить нужные настройки, проверить, что консоль сама не перезагрузилась.
5. Вручную подтвердить перезагрузку и затем проверить нужное USB-подключение.
6. В галерее открыть тестовые PNG на обеих картах, в том числе одноимённые.
   Проверить отмену удаления, затем удалить один тестовый файл и убедиться,
   что одноимённый на другой карте сохранился.

ДИАГНОСТИКА И УДАЛЕНИЕ ПРИЛОЖЕНИЙ
В папке каждого приложения: app.log, предыдущий запуск — app-previous.log.
Если не запускается/не работают кнопки/статус неизвестен — пришлите app.log.
Программы используют системные SDL 1.2/SDL_image/SDL_ttf GarlicOS; системные
библиотеки не заменяются. j2k.so взят без изменений из вашего DinguxCommander.
Для удаления достаточно убрать соответствующий .sh, папку приложения и PNG
из Imgs. Это не откатывает USB-флаги: нужные флаги выберите до удаления.
Удаление USB Manager не удаляет ранее установленный MTP-сервер.

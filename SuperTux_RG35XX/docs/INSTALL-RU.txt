SuperTux для оригинальной RG35XX / GarlicOS 1.4.9
Русская версия 0.2.2; английский порт 0.1.2.

ПОЛНАЯ РУССКАЯ ВЕРСИЯ
Распакуйте SuperTux_RG35XX_v0.2.2_RU.zip в корень карты с играми.
Объедините Roms. Должны появиться:
Roms/PORTS/SuperTux.sh
Roms/PORTS/SuperTux/supertux
Roms/PORTS/SuperTux/data.pak
Roms/PORTS/Imgs/SuperTux.png
Запуск: PORTS → SuperTux. Данные включены, новые библиотеки не нужны.

АНГЛИЙСКАЯ ВЕРСИЯ И РУСИФИКАТОР
Английская сборка: SuperTux_RG35XX_v0.1.2_EN.zip.
Поверх неё можно распаковать SuperTux_RG35XX_v0.2.2_russifier.zip.
Для полной русской сборки отдельный русификатор не нужен.

УПРАВЛЕНИЕ
Крестовина: движение / меню; вниз: пригнуться.
A: прыжок / подтверждение / вход в уровень.
B: бег / стрельба / действие; в меню — назад.
Бег и стрельба объединены в одно действие.
START: пауза в уровне; подтверждение в открытом меню.
MENU / SELECT: игровое меню и возврат.
VOL+ / VOL-: системная громкость.
X/Y доступны для назначения. L1/R1/L2/R2 полностью игнорируются.
Назначение: выбрать строку → A → нужная кнопка. MENU отменяет ввод.
Прокрутка не меняет привязки. «Сбросить управление» возвращает исходные назначения.

ВЫХОД
Удерживайте MENU не менее 1,5 с: настройки и прогресс карты записываются,
игра штатно завершается. Позиция внутри незавершённого уровня не сохраняется.
Короткое MENU по-прежнему открывает меню.
MENU → Покинуть уровень; на карте MENU → В главное меню; затем Выход.
На английском: Abort Level → Quit Game → Quit.

СОХРАНЕНИЯ
Roms/PORTS/SuperTux/Saves/.supertux/
При обновлении сохраните Saves. Личных сохранений в архивах нет.
Английские слоты совместимы с русской версией.
Слот записывается при штатном выходе с карты в главное меню.

ЖУРНАЛ
Roms/PORTS/SuperTux/Logs/run.log
Предыдущий запуск: run.prev.log.
Сообщение об отсутствии config при первом запуске нормально.

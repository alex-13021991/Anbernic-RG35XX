## SuperTux для оригинальной RG35XX / GarlicOS 1.4.9

Родное разрешение **640×480**, звук, управление кнопками и русский текст. Переведены меню, HUD, сообщения, названия уровней, вступление, концовки и титры. Логотип и игровые картинки сохранены.

### Что исправлено в 0.2.1

Исправлен короткий чёрный экран и немедленный выход при запуске установленной игры из **PORTS**. GarlicOS передаёт приложению 32-битный RGB framebuffer; прежняя сборка принимала только RGB565. Теперь поддерживаются оба режима. Исправленный обычный запуск из PORTS проверен на приставке.

### Установка и обновление

Распакуйте выбранный полный архив в корень карты с играми, объединяя **Roms**. Запуск: **PORTS → SuperTux**. Для отдельного русификатора сначала установите EN, закройте игру и распакуйте дополнение в корень той же карты.

При обновлении сохраните **Roms/PORTS/SuperTux/Saves/**. Личные сохранения в релиз не включены. Английские слоты совместимы с русской версией. Журнал: SuperTux/Logs/run.log.

### Управление

- Крестовина — движение и меню; вниз — пригнуться.
- **A — прыжок / подтверждение / вход в уровень.**
- **B — бег / стрельба / действие; в меню — назад.**
- START — пауза в уровне; подтверждение при открытом меню.
- MENU / SELECT — игровое меню и возврат.
- VOL+ / VOL− — системная громкость.

Бег и стрельба в SuperTux используют одно действие. Выход: MENU → Покинуть уровень; на карте MENU → В главное меню; затем Выход.

### Исходники по слоям

В корне репозитория добавлен [SuperTux_RG35XX](https://github.com/alex-13021991/Anbernic-RG35XX/tree/main/SuperTux_RG35XX).

1. sources/upstream/ — оригинальный снимок andrigamerita; отдельно сохранён полный снимок dmitrysmagin и полноразмерные исторические ресурсы.
2. patches/rg35xx/ — патч порта для оригинальной RG35XX.
3. patches/russian/ — следующий патч русификации, bitmap-шрифты, источник DejaVu и лицензия.

Восстановление и сборка EN/RU автоматизированы; исходники игры из сети скачивать не нужно. Нужны Miyoo GCC 7.3.0 и sysroot GarlicOS. [Инструкция по сборке](https://github.com/alex-13021991/Anbernic-RG35XX/blob/main/SuperTux_RG35XX/docs/BUILD-RU.md).

### Проверки и лицензии

Владелец подтвердил игру и кнопки в 640×480, русский текст и загрузку английского сохранения. После исправления framebuffer отдельно проверен установленный запуск из PORTS. Оба варианта пересобраны из слоёв; проверены SHA-256, ABI, UTF-8, ресурсы и наложение отдельного русификатора на EN.

Все 660 игровых изображений, 20 эффектов и 14 музыкальных файлов между EN и RU совпадают побайтно. Длительное прохождение всех уровней и замеры FPS на железе не проводились.

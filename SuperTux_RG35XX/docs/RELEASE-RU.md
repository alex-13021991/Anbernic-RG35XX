## SuperTux RG35XX 0.2.2 — управление, один PAK и превью

Для оригинальной RG35XX с GarlicOS 1.4.9. Родное разрешение **640×480**, русский интерфейс и поддержка RGB565/32-битного framebuffer.

### Изменения

- Исправлено переназначение: обычная прокрутка больше не записывает «вниз» во все действия.
- Выберите действие, нажмите **A**, затем кнопку крестовины или **A/B/X/Y**. Во время захвата B назначается, а не закрывает меню.
- MENU отменяет захват; добавлен **«Сбросить управление»**. Привязки сохраняются после перезапуска.
- **L1/R1/L2/R2 полностью игнорируются**, как попросил владелец.
- **Удержание MENU 1,5 с** штатно завершает приложение с записью настроек и прогресса карты. Короткое MENU открывает игровое меню.
- Все 795 ресурсов RU собраны в **один data.pak без сжатия**, с индексом имён/смещений/размеров и CRC32. Игра читает его напрямую, без распаковки при старте.
- По просьбе владельца имя героя исправлено на **Тукс** во всём русском тексте и склонениях.
- Добавлено предоставленное владельцем превью **Roms/PORTS/Imgs/SuperTux.png** без изменения PNG.

### Установка и обновление

Закройте игру и распакуйте полный архив в корень карты с играми с объединением **Roms**. Запуск: **PORTS → SuperTux**.

Сохраните **SuperTux/Saves/**. В архивах нет личных сохранений. Старые слоты совместимы. При обновлении с 0.2.1 после успешного запуска можно удалить старую папку **SuperTux/data/**: теперь используется **data.pak**. Не удаляйте Saves и data.pak.

### Управление

Крестовина — движение; **A — прыжок**, **B — бег/стрельба/действие**. X/Y доступны для переназначения. START — пауза. Короткое MENU / SELECT — игровое меню; долгое MENU — выход. VOL+ / VOL− — громкость. Плечевые кнопки игнорируются.

Для исправления уже испорченных назначений откройте Настройки → Управление → Сбросить управление.

### Проверки

Владелец подтвердил игру из PAK, звук, исправленные настройки кнопок и выход удержанием MENU на приставке. QEMU проверил реальный evdev-ввод, A/B/X/Y, отмену, игнор плечевых кнопок, сброс, перезапуск и выход удержанием MENU из уровня с записью слота. Сборка испытана **без папки data/**.

Оба варианта пересобраны из раздельных слоёв. Упаковщик побайтно сверяет файлы PAK с исходными ресурсами; исходные игровые картинки, музыка и звуки сохранены. Проверяются ABI, CRC архивов и наложение русификатора на EN.

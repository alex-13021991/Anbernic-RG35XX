# История изменений

## 0.2.2 / английская база 0.1.2 — 28.11.2026

- Переназначение включается явно по A; прокрутка больше не перезаписывает действия.
- B корректно назначается; X/Y распознаются и показываются своими именами.
- Добавлены отмена захвата, сброс управления и перестановка конфликтующего назначения.
- L1/R1/L2/R2 игнорируются по просьбе владельца.
- Удержание MENU 1,5 с штатно завершает игру с записью настроек и прогресса карты.
- 795 ресурсов RU собраны в один индексированный data.pak без сжатия и без распаковки при запуске.
- Добавлено предоставленное владельцем превью без изменения исходного PNG.

## 0.2.1 / английская база 0.1.1 — 28.11.2026

- Исправлен короткий чёрный экран и выход при запуске из PORTS.
- Добавлен 32-битный RGB framebuffer наряду с RGB565.
- В журнал выводятся реальные параметры экрана.
- Подготовлены исходная база, раздельные патчи RG35XX и русификации, скрипты сборки и отдельный установочный русификатор.
- Проверено восстановление из слоёв, включая исходные ресурсы с CRLF.

## 0.2.0 — 28.11.2026

- Русские меню, HUD, сообщения, названия уровней, сюжет и титры.
- UTF-8 и кириллица с Ё/ё, отдельные bitmap-шрифты.
- Совместимость с английскими слотами.
- Игровые картинки, музыка и эффекты сохранены.

## 0.1.0 — 28.11.2026

- Первый порт RG35XX / GarlicOS 1.4.9.
- Родной кадр 640×480 и восстановленные полноразмерные ресурсы.
- evdev; A — прыжок, B — бег/стрельба/действие.
- Проверен RAM-запуск по ADB, кнопки и выход.
- Backend принимал только RGB565; ограничение снято в 0.1.1/0.2.1.

Имя героя в русском тексте: **Тукс** (Tux), включая склонения; название SuperTux и логотип сохранены.

# Переключатели ADB, USB-ввода и MTP

Три отдельных пункта меню APPS для оригинальной RG35XX с GarlicOS 1.4.9.

- **Toggle ADB** включает или выключает ADB. При включении снимает флаг USB-ввода.
- **Toggle USB** переключает USB-ввод для геймпадов. При включении снимает флаги ADB и MTP.
- **Toggle MTP** переключает передачу файлов. При включении проверяет установку MTP-сервера, снимает флаг USB-ввода и сохраняет настройку ADB.

## Установка

Выключите консоль. Скопируйте содержимое `ROMS/Roms/APPS` из ZIP в `Roms/APPS` на карте, с которой запускаете приложения. Скопируйте также папки `Toggle USB` и `Imgs`. Вставьте карту, выберите нужный переключатель в APPS и перезагрузите приставку, чтобы применить настройку. Завершите передачу файлов перед перезагрузкой.

Для режима MTP установите сервер на системную карту TF1 по его инструкции. Если уже используете USB Manager с работающим MTP, переключатели используют тот же сервер. Меняйте режим одним приложением за раз.

Для удаления уберите три скрипта `Toggle ADB.sh`, `Toggle USB.sh`, `Toggle MTP.sh`, папку `Toggle USB` и три соответствующие обложки из `Imgs`.

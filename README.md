# Anbernic RG35XX

Утилиты для оригинальной Anbernic RG35XX с GarlicOS 1.4.9. Выберите программу и скачайте установочный ZIP из её релиза.

| Программа | Назначение | Релиз |
| --- | --- | --- |
| [System Info RU](System-Info-RU/) | Системная информация и статистика коллекции на обеих картах. | [1.1.0](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/system-info-ru-v1.1.0) |
| [USB Manager](USB-Manager/) | Настраивает MTP, ADB и USB-ввод. | [0.1.3](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/usb-manager-v0.1.3) |
| [Screenshot Viewer](Screenshot-Viewer/) | Просмотр и удаление скриншотов с TF1 и TF2. | [0.1.3](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/screenshot-viewer-v0.1.3) |

Утилиты для оригинальной Anbernic RG35XX с GarlicOS 1.4.9. Выберите программу и скачайте установочный ZIP из её релиза.

| [System Info RU](System-Info-RU/) | Системная информация и статистика коллекции на обеих картах. | [1.1.1](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/system-info-ru-v1.1.1) |
| [USB Manager](USB-Manager/) | Настраивает MTP, ADB и USB-ввод. | [0.1.5](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/usb-manager-v0.1.5) |
| [Screenshot Manager](Screenshot-Manager/) | Включает и выключает службу съёмки экрана по L2 + R2. | [0.1.0](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/screenshot-manager-v0.1.0) |
| [Screenshot Viewer](Screenshot-Viewer/) | Просмотр и удаление скриншотов с TF1 и TF2. | [0.1.5](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/screenshot-viewer-v0.1.5) |
| [MTP Server](MTP-Server/) | Сервер передачи файлов по USB для USB Manager и Toggle MTP. | [2026.11.18](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/mtp-server-2026.11.18) |
| [Переключатели USB](USB-Toggles/) | Три пункта APPS для ADB, USB-ввода и MTP. | [2026.11.18](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/usb-toggles-2026.11.18) |
| [Dingux Commander Dark RU](Dingux-Commander-RU/) | Двухпанельный файловый менеджер с русским интерфейсом. | [21.11.2026](https://github.com/alex-13021991/Anbernic-RG35XX/releases/tag/dingux-commander-dark-ru-2026.11.21) |

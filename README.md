# Anbernic RG35XX

Утилиты и игровые порты для оригинальной Anbernic RG35XX с GarlicOS 1.4.9. Выберите программу и скачайте установочный ZIP из её релиза.

Для самостоятельной сборки: [тулчейны и русские инструкции](Toolchains/), включая архив Miyoo GCC 7.3.0, сохранённый в этом репозитории.
